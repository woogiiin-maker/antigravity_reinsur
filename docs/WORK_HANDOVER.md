## 1. 🏠 ↔ 🏢 집과 회사 전환 작업 가이드 (동기화 방법)

집과 회사 어디서든 작업 연속성을 유지하기 위한 체크리스트입니다.

### [집(Home) 또는 회사(Office)에 도착하여 작업 시작할 때]
1. 터미널에서 최신 소스코드 다운로드:
   ```bash
   git pull origin main
   ```
   *또는 프로젝트 루트의 `sync.bat` 파일을 더블 클릭하여 자동 동기화 실행*
2. 의존성 확인 (최초 1회 또는 패키지 변경 시):
   ```bash
   npm install
   ```
3. 로컬 개발 서버 시작:
   ```bash
   npm run dev
   ```
   (브라우저에서 `http://localhost:3000` 접속)

### [작업을 마치고 퇴근/귀가 전 필수 작업]
1. 변경 사항을 GitHub에 커밋 및 푸시:
   ```bash
   git add -A
   git commit -m "feat/fix: 작업 내용 요약"
   git push origin main
   ```
   *또는 프로젝트 루트의 `sync.bat` 파일을 더블 클릭하면 자동으로 fetch, pull, commit, push가 원클릭으로 완료됩니다.*

## 3. 🧠 핵심 아키텍처 및 보장 판정 규칙 (Domain Engine)

### 9대 핵심 보장 및 심사 기준
1. **일반암 진단비 (`cancer`)**: 특정 부위(유방/자궁 등 남녀특정암), 유사암, 소액암, CI 한정을 완전 배제한 순수 일반암 100% 지급 담보만 인정.
2. **비급여암 주요치료비 (`nonReimbursedCancer`)**: '비급여'와 '암 주요치료비'가 모두 포함되어 비급여 암수술/약물/방사선을 종합 보장하는 담보만 인정 (표적약물, 로봇수술 단독 제외).
3. **암 주요치료 생활비 (`cancerLivingCare`)**: 암 치료 기간 연간 생활자금 지원 담보.
4. **항암 중입자·양성자 치료비 (`heavyParticle`)**: 중입자 가속 및 양성자 방사선 치료 담보.
5. **뇌혈관질환 진단비 (`brain`)**: I60~I69 전체 뇌혈관 질환 보장만 인정 (뇌졸중/뇌출혈/뇌경색 한정 제외).
6. **허혈성심장질환 진단비 (`heart`)**: 협심증(I20) 및 급성심근경색을 포함하는 심질환 전체 보장만 인정 (급성심근경색 한정 제외).
7. **상해/재해 후유장해 (`injuryDisability`)**: 3% 이상 지급률 상해/재해 장해.
8. **질병 80% 이상 고도후유장해 (`diseaseDisability80`)**: 질병 80% 이상 중증 후유장해.
9. **질병/상해 1~5종 수술비 (`surgery`)**: 포괄적 1~5종 수술비 (골절/화상/백내장/부인과 등 질환 한정 수술비 제외).
10. **순환계질환 주요치료비 (`circulatoryCare`)**: 뇌·심장 순환계 질환 주요치료 종합 보장.
11. **실손의료비 (`indemnity`)**: 입원/통원 의료비 실손 보상.
